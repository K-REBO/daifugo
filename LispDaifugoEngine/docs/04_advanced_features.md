# 4. 高度な機能

LispDaifugoEngine は、ゲームの基本機能に加えて、より複雑なアプリケーションを構築するための高度な機能を提供します。

## 4.1. イベントシステム (`daifugo-event-system`)

イベントシステムは、ゲーム内の様々な出来事を非同期に通知し、コンポーネント間の疎結合な連携を可能にします。これにより、UIの更新、ログの記録、外部システムとの連携などを、ゲームのコアロジックに影響を与えることなく実装できます。

### 4.1.1. イベントの種類

イベントシステムは、以下のような様々なイベントを通知します。

- **ゲームイベント**: ゲームの開始、終了、プレイヤーの勝利など。
- **ターンイベント**: ターンの開始、終了、プレイヤーのパスなど。
- **カードイベント**: カードがプレイされた時、デッキがシャッフルされた時など。
- **ルールイベント**: ルールが適用された時、革命が起きた時など。

### 4.1.2. イベントリスナー

他のコンポーネントは、特定のイベントに対するリスナーを登録することで、イベント発生時に通知を受け取ることができます。

- `(register-event-listener event-type callback)`: 指定されたイベントタイプのリスナーを登録します。
- `(unregister-event-listener listener-id)`: 登録されているリスナーを解除します。

### 4.1.3. 非同期処理

イベントシステムは非同期処理をサポートしており、重い処理（例：ネットワーク通信、ファイルI/O）をゲームのメインループをブロックすることなく実行できます。

- `(register-async-listener event-type callback)`: 非同期に実行されるリスナーを登録します。

## 4.2. ロギングシステム (`daifugo-game-logger`)

ロギングシステムは、ゲームのデバッグ、テスト、分析を支援するための強力なツールです。

### 4.2.1. ログレベル

ログは、以下の4つのレベルで記録されます。

- **DEBUG**: デバッグ用の詳細な情報。
- **INFO**: ゲームの進行状況を示す一般的な情報。
- **WARN**: 予期しないが、致命的ではない問題。
- **ERROR**: ゲームの進行に影響を与える可能性のあるエラー。

### 4.2.2. ゲーム専用ログ

ロギングシステムは、大富豪のゲームに特化したログを記録するための関数を提供します。

- `(log-player-action player-id action)`: プレイヤーのアクションを記録します。
- `(log-card-play player-id cards play-type)`: カードのプレイを記録します。
- `(log-rule-applied rule-name description)`: ルールが適用されたことを記録します。

### 4.2.3. 出力フォーマット

ログは、テキスト、JSON、CSVなど、様々なフォーマットで出力することができます。これにより、他のツールでの分析や可視化が容易になります。
