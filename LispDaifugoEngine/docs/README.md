# LispDaifugoEngine ドキュメント

これは LispDaifugoEngine の公式ドキュメントです。このエンジンは、柔軟なルール設定と拡張性を備えた大富豪ゲームを Common Lisp で実装したものです。

## ドキュメント構成

このドキュメントは、以下のセクションで構成されています。

- **[00_introduction.md](./00_introduction.md)**: プロジェクトの概要と目的について説明します。
- **[01_architecture.md](./01_architecture.md)**: システム全体のアーキテクチャと設計思想について解説します。
- **[02_core_systems.md](./02_core_systems.md)**: ゲームの核となるシステム群（ゲームエンジン、カードシステム、プレイヤーシステムなど）について詳述します。
- **[03_rules.md](./03_rules.md)**: ルールエンジンと、実装されている各種ルール（8切り、革命など）について解説します。
- **[04_advanced_features.md](./04_advanced_features.md)**: イベントシステムやロガーなど、高度な機能について説明します。
- **[05_api_and_utils.md](./05_api_and_utils.md)**: 外部からエンジンを利用するためのAPIや、内部で使われるユーティリティ関数について解説します。
- **[06_how_to_use.md](./06_how_to_use.md)**: 開発者向けに、このエンジンの使い方やセットアップ方法をガイドします。

各ファイルを参照して、エンジンの詳細を理解してください。
