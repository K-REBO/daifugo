# 0. はじめに

## 0.1. プロジェクト概要

LispDaifugoEngine は、Common Lisp で実装された柔軟で拡張性の高い大富豪（大貧民）ゲームエンジンです。日本の代表的なカードゲームである大富豪を、様々なローカルルールやカスタムルールに対応できるよう設計されています。

このプロジェクトの主な目的は以下の通りです。

- **高い拡張性**: 新しいルールや機能を簡単に追加できる、モジュール化されたアーキテクチャを提供します。
- **柔軟なルール設定**: 8切り、革命、都落ちといった一般的なルールから、スペ3返しや縛りといった特殊なルールまで、自由に組み合わせることができます。
- **明確な API**: 外部のクライアント（UIなど）がゲームエンジンと容易に連携できるよう、整然としたAPIを提供します。
- **堅牢なテスト**: Common Lisp のテストフレームワークを活用し、安定した動作を保証します。

## 0.2. 対象読者

このドキュメントは、以下の読者を対象としています。

- **LispDaifugoEngine を利用する開発者**: このエンジンを使って新しいゲームやアプリケーションを構築したい方。
- **ゲームのルールやロジックに興味がある方**: 大富豪のルールがどのようにコードで実装されているかを知りたい方。
- **Common Lisp の実践的な例を探している方**: 中規模な Lisp プロジェクトの構造や設計を学びたい方。
