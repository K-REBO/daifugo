# LispDaifugoEngine - ブラウザ版

LispDaifugoEngineのブラウザ版実装です。Deno Lispインタープリターをブラウザで動作させ、インタラクティブなゲーム体験を提供します。

## 🚀 特徴

- **ブラウザ版Lisp REPL**: リアルタイムでLisp式を評価
- **インタラクティブゲーム**: ブラウザ上で大富豪ゲームをプレイ  
- **システムテスト**: LispDaifugoEngineの動作をテスト
- **モダンUI**: レスポンシブなWebインターフェース

## 🎮 使用方法

### 1. ブラウザで開く

```bash
# 簡単なHTTPサーバーを起動
python -m http.server 8080

# ブラウザでアクセス
open http://localhost:8080/browser/
```

### 2. Lisp REPL

**基本的な算術演算:**
```lisp
(+ 1 2)      ; => 3
(* 4 5)      ; => 20
(- 10 3)     ; => 7
```

**LispDaifugoEngine関数:**
```lisp
(create-deck)           ; デッキを作成
(create-game 4)         ; 4人プレイヤーのゲームを作成
(format t "Hello~%")    ; 文字列を出力
```

**リスト操作:**
```lisp
(list 1 2 3)           ; リストを作成
(length (list 1 2 3))  ; リストの長さ
(car (list 1 2 3))     ; 最初の要素
(cdr (list 1 2 3))     ; 残りの要素
```

### 3. ゲームプレイ

1. **新しいゲーム**ボタンをクリック
2. カードが自動配布される
3. 現在のプレイヤーの手札からカードを選択
4. **カードを出す**または**パス**を選択

### 4. システムテスト

**全テスト実行**ボタンをクリックして、以下のテストを実行:

- カードシステムテスト
- プレイヤーシステムテスト  
- ルールエンジンテスト
- ゲームロジックテスト
- ゲームエンジンテスト
