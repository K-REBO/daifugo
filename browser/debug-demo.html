🔍 大富豪ゲーム デバッグシステム デモ

📋 デバッグ機能一覧

  • ✅ ゲーム状態のリアルタイム記録
  • ✅ プレイヤーアクションの詳細ログ
  • ✅ CPUの思考プロセス記録
  • ✅ ルールトリガーイベントの追跡
  • ✅ エラーとスタックトレースの記録
  • ✅ JSON形式でのデータエクスポート
  • ✅ 人間が読みやすいログ形式でのエクスポート
  • ✅ クリップボードへのコピー機能

🎮 使用方法

  1. 右上の「🔍 Debug」ボタンをクリック
  2. 「⏺️ 記録開始」でデバッグ記録を開始
  3. ゲームをプレイして動作を記録
  4. 「💾 エクスポート」でデータを保存
  5. 必要に応じてデータをクリア

📄 記録されるデータ

プレイヤーアクション

  • • カード選択/選択解除
  • • カードプレイ（成功/失敗）
  • • パス（成功/失敗）
  • • CPU思考と決定プロセス

ゲーム状態

  • • プレイヤーの手札情報
  • • 場に出されたカード
  • • 現在のターン情報
  • • ゲーム進行状況

ルールイベント

  • • 革命（4枚同時出し）
  • • 8切り（場クリア）
  • • 11バック（逆方向プレイ）
  • • その他のルールトリガー

エラー情報

  • • エラーメッセージ
  • • スタックトレース
  • • エラー発生時のコンテキスト
  • • デバッグ用詳細情報
🎮 ゲームを開始してデバッグを試す
